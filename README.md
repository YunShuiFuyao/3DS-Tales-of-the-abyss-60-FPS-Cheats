# 3DS-Tales-of-the-Abyss-60-FPS-Cheats

60FPS cheats for *Tales of the Abyss 3D* (深渊传说 3D), designed for Luma3DS (CFW) and 3DS emulators (Citra / Azahar).  
This project is for learning and technical research only.

## 特性亮点 (Features)

- **真·原生 1.0x 原速 60FPS**：不同于传统强行拉高全局时间步长导致的 1.4x–2.0x 加速，本金手指在非战斗场景启用了引擎内置的原生 60FPS 档位（`+0x54 = 0`），确保地图子系统、计时器与事件节拍均以精准 1.0 倍速运行。
- **全场景独立分流**：
  - **战斗画面 (`Btl`)**：保留独立验证的战斗 60FPS 逻辑与整数步进修复。
  - **城镇与迷宫 (`Main`)**：修复了 60FPS 下满推摇杆退化为走路动画的问题，1:1 还原原版摇杆走/跑切换手感。
  - **世界大地图 (`Field`)**：对未做时间步长归一化的大地图移动速度与动画周期进行同步 0.5x 补偿，避免 2 倍速与滑步。
  - **过场影片 (`Movie`)**：自动回落原生 30FPS，防止播片音画不同步。

## 安装与使用 (Installation)

> ⚠️ **注意**：请勿同时勾选旧版 60FPS 金手指，否则会导致指令冲突、倍速异常或崩溃。

### 1. 3DS 实机（Luma3DS）
1. 将对应版本的 `cheats.txt`（或 `<TitleID>.txt`）复制到 SD 卡目录：  
   `sdmc:/luma/titles/<TitleID>/cheats.txt`（或在 `sdmc:/cheats/<TitleID>.txt` 中按 TitleID 命名）。
2. 启动游戏后，按下 `L + 下方向键 + Select` 打开 Rosalina 菜单。
3. 进入 **Cheats**，勾选 `[60FPS (v1.1)]` 并保存。
4. **New 3DS / New 2DS 强烈建议**：在 Rosalina 菜单的 **New 3DS menu** 中开启 `Clock: 804MHz` 与 `L2 Cache: Enabled`，以获得更稳定的 60 帧表现。

### 2. 模拟器（Citra / Azahar）
1. 在游戏列表中右键点击《深渊传说》，选择 **属性 (Properties) → 金手指 (Cheats)**。
2. 点击 **添加金手指 (Add Cheat)**，粘贴本仓库提供的代码并勾选启用。
3. 建议在设置中关闭不兼容的外部跳帧补丁，重进一次场景或读档生效。

## 技术原理简述 (Technical Notes)

本金手指最初参考了 PS2 版《深渊传说》的 60FPS 补丁思路（两作底层架构高度相似），并在此基础上对 3DS `code.bin` 进行了针对性逆向与修补：

- **解锁引擎原生 60FPS 档位**：原版在进入 `Main`、`Btl`、`Field` 等场景时会强制写入 30FPS 档位字节（`off_50190C + 0x54 = 1`），并通过 `sub_2A8730` 计算派生时间步长。非战斗非播片场景下切回原生 `0` 档后，浮点步长自然归位为 `1.0f`，地图子系统（`sub_34E2D0`）回调频率与 `sub_34B424` 节拍周期均自动适配 60Hz。
- **修正玩家与 NPC 走/跑判定阈值**：由于 60FPS 下单帧位移减半，将玩家状态切换函数 `sub_22A0D0` 的独立常量池阈值（`0x0022A154`）由 `14.0f` 调整为 `7.0f`，同时将路径跟随函数 `sub_228C1C`（`0x0022917C`）的阈值由 `8.0f` 调整为 `2.0f`。
- **大地图速度同步补偿**：大地图控制器 `sub_33ADC4` 的位移增量未乘以 `dt`，通过将常量池 `0x0033C9B8`（`4.0f → 2.0f`）与 `0x0033C9BC`（`2.0f → 1.0f`）减半，实现位移与动画周期同步 0.5x 补偿。
- **战斗与影片场景分流**：基于场景 ID（`0x0050142C`）动态分流——战斗场景（`8`）保留 `*(off_5067C0) = 1` 与专属参数；影片场景（`5`）自动还原原版 30FPS 指令。
